# Open Source 5G Core Network Deployment Guides

This repository contains step-by-step deployment guides for open source 5G core network implementations on Kubernetes.

## Guides

- [Free5GC Deployment](docs/free5gc_Deployment.md) — Single cluster, multi-node deployment of Free5GC using Cilium, Multus, and UERANSIM.
- [OAI 5G Core Deployment](docs/OAI_Deployment.md) — Single cluster, multi-node deployment of OAI 5G Core with OAI RAN or UERANSIM.

## Environment

- **OS:** Ubuntu 22.04.5 LTS
- **Kubernetes:** v1.29
- **CNI:** Cilium + Multus
- **Helm:** v3
